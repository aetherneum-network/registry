# History rewrite of 2 October 2026: map of cited hashes

On 2 October 2026 the history of the `aetherneum-network` repositories was rewritten to replace an e-mail address in the author and committer fields of some commits. File contents did not change: every rewritten commit has exactly the same tree as the commit it replaces, and the commit count of every branch is the same.

- Commits signed with the organization owner's SSH key were signed again with the same key.
- Signed commits with nothing to change kept their hash and their original signature.
- A few merge commits made through the GitHub web interface sit on top of rewritten commits; GitHub's own signature cannot be reproduced, so those merges are now unsigned.

Frozen records (changelogs, manifests, `eval/history.json`, documents of a freeze) are **not** edited: they keep the hashes they were frozen with. The tables below map every such hash to its commit after the rewrite.

Check one mapping in a clone of the repository:

```bash
git rev-parse <new>^{tree}   # equals the tree in the table
```
